# 🎮 Video Games Sales Analysis

## 📌 Project Overview
This project explores video game sales data using Python and data analysis techniques. It aims to identify sales patterns, compare regional performance, and visualize trends in the video game industry.

## 🎯 Objectives
- Explore and understand the video game sales dataset.
- Analyze sales across different regions.
- Identify trends and patterns in video game sales.
- Present findings through charts and visualizations.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Project Files
- `VideoGamesYoutubeProject.ipynb` — Jupyter Notebook containing the analysis and visualizations.
- `VideoGamesSales.csv` — Dataset used for the analysis.

## 🚀 How to Run the Project
1. Download both project files from this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Keep the notebook and CSV file in the same folder.
5. Open `VideoGamesYoutubeProject.ipynb` in Jupyter Notebook.
6. Run the notebook cells in order.

## 📊 Analysis
The notebook contains data analysis and visualizations, including charts such as bar charts, box plots, pie charts, and line charts.
